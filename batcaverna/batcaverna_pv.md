# ⚡ 1. Circuitos Elétricos CC - EDO de 1 e 2 Ordem (RC / RL / RLC)

****

A análise transiente de um circuito resistor-capacitor (RC) em série excitado por um degrau de tensão $V_s$ é descrita pela seguinte Equação Diferencial Ordinária (EDO):

$$R C \frac{dv_c(t)}{dt} + v_c(t) = V_s$$

Com a condição inicial $v_c(0) = V_0$. A solução geral simbólica é:

$$v_c(t) = V_s + (V_0 - V_s) e^{-\frac{t}{RC}}$$

Abaixo, utilizamos o `SymPy` no Python para resolver a EDO simbolicamente e plotar a curva transiente para $R = 1\ k\Omega$, $C = 1\ mF$, $V_s = 10\ V$ e $V_0 = 0\ V$:

```{python}
#| label: rc-transient
#| echo: true
import sympy as sp
import numpy as np
import matplotlib.pyplot as plt

# 1. Resolução Simbólica via SymPy
t = sp.Symbol("t", real=True, positive=True)
R, C, Vs, V0 = sp.symbols("R C V_s V_0", real=True, positive=True)
vc = sp.Function("v_c")

edo = R * C * sp.diff(vc(t), t) + vc(t) - Vs
sol = sp.dsolve(edo, vc(t), ics={vc(0): V0})

print("Solução simbólica da EDO:")
display(sol)

# 2. Substituição de valores numéricos para plotagem
sol_num = sol.rhs.subs({R: 1000, C: 1e-3, Vs: 10, V0: 0})
v_func = sp.lambdify(t, sol_num, "numpy")

t_vals = np.linspace(0, 5, 500)
```

# 🔢 3. Otimização de Recursos em Julia (JuMP & HiGHS)

A otimização linear é fundamental no despacho econômico de energia e alocação de recursos. Abaixo, formulamos um problema para minimizar o custo de geração de energia atendendo a uma demanda mínima de $100\ MW$:

$$\min_{x_1, x_2} \quad 20 x_1 + 30 x_2$$

Sujeito a:
$$x_1 + x_2 \ge 100 \quad \text{(Atendimento da Demanda)}$$
$$0 \le x_1 \le 80 \quad \text{(Limite do Gerador 1)}$$
$$0 \le x_2 \le 60 \quad \text{(Limite do Gerador 2)}$$

A modelagem é feita em Julia com **JuMP.jl** e resolvida pelo solver **HiGHS**:

```{julia}
using JuMP
using HiGHS
using DifferentialEquations
using Plots

# EDO y'' + y = 0, escrita como um sistema de primeira ordem:
# y' = v e v' = -y. As condições iniciais geram seno e cosseno.
function oscilador!(du, u, p, t)
    du[1] = u[2]
    du[2] = -u[1]
end

intervalo = (0.0, 2π)
sol_seno = solve(ODEProblem(oscilador!, [0.0, 1.0], intervalo),
    Tsit5(), saveat=0.01)
sol_cosseno = solve(ODEProblem(oscilador!, [1.0, 0.0], intervalo),
    Tsit5(), saveat=0.01)

tempo = sol_seno.t
seno = [u[1] for u in sol_seno.u]
cosseno = [u[1] for u in sol_cosseno.u]
tangente = [abs(c) > 1e-6 ? s / c : NaN for (s, c) in zip(seno, cosseno)]
cotangente = [abs(s) > 1e-6 ? c / s : NaN for (s, c) in zip(seno, cosseno)]

grafico = plot(tempo, seno, label="sen(t)", linewidth=2,
    xlabel="t (rad)", ylabel="valor", title="Funções trigonométricas via EDO")
plot!(grafico, tempo, cosseno, label="cos(t)", linewidth=2)
plot!(grafico, tempo, tangente, label="tan(t)", linestyle=:dash)
plot!(grafico, tempo, cotangente, label="cot(t)", linestyle=:dot)
ylims!(grafico, (-5, 5))
savefig(grafico, "funcoes_trigonometricas_edo.png")

# Inicializar modelo
modelo = Model(HiGHS.Optimizer)

# Variáveis
@variable(modelo, x1 >= 0)
@variable(modelo, x2 >= 0)

# Função Objetivo
@objective(modelo, Min, 20*x1 + 30*x2)

# Restrições
@constraint(modelo, rest_demanda, x1 + x2 >= 100)
@constraint(modelo, cap_gerador1, x1 <= 80)
@constraint(modelo, cap_gerador2, x2 <= 60)

# Resolver
optimize!(modelo)

println("Status: ", termination_status(modelo))
println("Geração G1: ", value(x1), " MW")
println("Geração G2: ", value(x2), " MW")
```

# ⚡ 1. Circuitos Elétricos CC: Resposta Transiente de 1ª Ordem (RC)

****
A análise transiente de um circuito resistor-capacitor (RC) em série excitado por um degrau de tensão $V_s$ é descrita pela seguinte Equação Diferencial Ordinária (EDO):

$$R C \frac{dv_c(t)}{dt} + v_c(t) = V_s$$

Com a condição inicial $v_c(0) = V_0$. A solução geral simbólica é:

$$v_c(t) = V_s + (V_0 - V_s) e^{-\frac{t}{RC}}$$

Abaixo, utilizamos o `SymPy` no Python para resolver a EDO simbolicamente e plotar a curva transiente para $R = 1\ k\Omega$, $C = 1\ mF$, $V_s = 10\ V$ e $V_0 = 0\ V$:

```{python}
#| label: rc-transient
#| echo: true
import sympy as sp
import numpy as np
import matplotlib.pyplot as plt

# 1. Resolução Simbólica via SymPy
t = sp.Symbol("t", real=True, positive=True)
R, C, Vs, V0 = sp.symbols("R C V_s V_0", real=True, positive=True)
vc = sp.Function("v_c")

edo = R * C * sp.diff(vc(t), t) + vc(t) - Vs
sol = sp.dsolve(edo, vc(t), ics={vc(0): V0})

print("Solução simbólica da EDO:")
display(sol)

# 2. Substituição de valores numéricos para plotagem
sol_num = sol.rhs.subs({R: 1000, C: 1e-3, Vs: 10, V0: 0})
v_func = sp.lambdify(t, sol_num, "numpy")

t_vals = np.linspace(0, 5, 500)
v_vals = v_func(t_vals)

# 3. Plotagem do gráfico
plt.figure(figsize=(8, 4))
plt.plot(
    t_vals, v_vals, label="$v_c(t)$ (Tensão no Capacitor)", color="#00ffff", linewidth=2
)
plt.axhline(10, color="red", linestyle="--", label="$V_s$ (Tensão da Fonte = 10V)")
plt.title("Resposta ao Degrau do Circuito RC", color="white")
plt.xlabel("Tempo (s)", color="white")
plt.ylabel("Tensão (V)", color="white")
plt.grid(True, linestyle=":", alpha=0.6)
plt.legend()
plt.show()
```
